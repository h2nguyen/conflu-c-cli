# A line is `METHOD path | QUERY | BODY`, or `METHOD path | QUERY | header: HEADERS | BODY` when the document names a header parameter. The method and the path template are
# those of the endpoint list of this API, in the same order. Only top-level names are listed, each part sorted by name.
# QUERY is `no query`, or `query: ` and the parameters: `*` after a name marks a required one, `<=N` the documented maximum of `limit`, `(deprecated)` one that the document marks as deprecated.
# BODY is `no body`; `body: ` and what a JSON body may be; or `not JSON (media type: form fields)` for a request that is not JSON, such as a multipart upload. `optional ` in front says that a request may have none.
# A JSON body is `{properties}` for an object (`*` marks a required property, `...` that other properties are accepted as well), `[]` for an array or `any` for anything; the alternatives of a oneOf are joined by ` or `.
